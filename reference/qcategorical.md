# Quantile function for categorical distribution

Alias for
[`draw_categorical()`](https://jsanchezalv.github.io/WARDEN/reference/draw_categorical.md)
using standard quantile-function naming.

## Usage

``` r
qcategorical(p, probs)
```

## Arguments

- p:

  Numeric between 0 and 1 (inclusive). Probability (same as `luck` in
  [`draw_categorical()`](https://jsanchezalv.github.io/WARDEN/reference/draw_categorical.md)).

- probs:

  Numeric vector of probabilities.

## Value

Integer: 1-based index.
