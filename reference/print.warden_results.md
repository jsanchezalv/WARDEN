# Print method for warden_results

Displays a summary of the structure of a WARDEN simulation results
object.

## Usage

``` r
# S3 method for class 'warden_results'
print(x, ...)
```

## Arguments

- x:

  A `warden_results` object returned by
  [`run_sim()`](https://jsanchezalv.github.io/WARDEN/reference/run_sim.md)
  or
  [`run_sim_parallel()`](https://jsanchezalv.github.io/WARDEN/reference/run_sim_parallel.md).

- ...:

  Additional arguments (ignored).

## Value

Invisibly returns `x`.
